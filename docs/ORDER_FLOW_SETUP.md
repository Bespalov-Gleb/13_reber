# Настройка многошагового оформления заказа

## Обзор

Реализован многошаговый процесс оформления заказа с интеграцией Яндекс.Карт для автоподсказок адресов и валидации зоны доставки.

## Новые компоненты

### 1. Система состояний
- `OrderState` - enum состояний оформления заказа
- `OrderContext` - хранение временных данных
- `OrderStateService` - управление состояниями

### 2. Интеграция с Яндекс.Картами
- `YandexMapsProvider` - реализация API для автоподсказок адресов
- Методы: `suggest_addresses()`, `geocode_address()`, `validate_delivery_zone()`

### 3. UI компоненты
- `OrderKeyboard` - клавиатуры для каждого шага
- `OrderHandlerHelpers` - вспомогательные методы для обработки

## Настройка

### 1. Получение API ключа Яндекс.Карт

1. Зарегистрируйтесь на [Яндекс.Разработчик](https://developer.tech.yandex.ru/)
2. Создайте проект и получите API ключ для JavaScript API и HTTP Геокодер
3. Добавьте ключ в `config.env`:
   ```
   YANDEX_MAPS_API_KEY=ваш_api_ключ
   ```

### 2. Настройка зоны доставки

В `order_handler_helpers.py` найдите строку:
```python
cafe_coordinates = (55.7558, 37.6176)  # Moscow coordinates as example
```

Замените на координаты вашего кафе:
```python
cafe_coordinates = (ваша_широта, ваша_долгота)
```

### 3. Настройка максимального расстояния доставки

В `yandex_maps.py` в методе `validate_delivery_zone`:
```python
max_distance: float = 5000  # 5km default
```

Измените на нужное расстояние в метрах.

## Процесс оформления заказа

### Последовательность шагов:

1. **Выбор способа получения** (доставка/самовывоз)
2. **Выбор способа оплаты** (онлайн/наличными)
3. **Если доставка:**
   - Ввод адреса → автоподсказки Яндекс (топ-5 кнопок)
   - Проверка зоны доставки → ошибка + предложение самовывоза если вне зоны
   - Ввод телефона для доставки
4. **Выбор времени** (как можно скорее/к определенному времени)
5. **Если к определенному времени:** ввод времени
6. **Комментарий к заказу** (опционально)
7. **Подтверждение заказа**

### Навигация

- Кнопка "⬅️ Назад" возвращает на предыдущий шаг
- Кнопка "❌ Отменить" возвращает в корзину и сбрасывает контекст

## Особенности

### Автоподсказки адресов
- Использует Яндекс Suggest API
- Показывает топ-5 вариантов как кнопки
- Возможность ввода адреса вручную

### Валидация зоны доставки
- Проверяет расстояние от кафе до адреса
- Если адрес вне зоны - показывает ошибку с предложением самовывоза
- Использует формулу Haversine для расчета расстояния

### Состояния и контекст
- Каждый пользователь имеет свой контекст оформления
- Контекст автоматически очищается после создания заказа или отмены
- Поддержка навигации назад по всем шагам

## Тестирование

1. Добавьте товары в корзину
2. Нажмите "🚚 Оформить заказ"
3. Пройдите все шаги оформления
4. Проверьте автоподсказки адресов
5. Проверьте валидацию зоны доставки
6. Убедитесь, что заказ создается с правильными данными

## Возможные улучшения

1. **Кэширование** - кэшировать результаты геокодирования
2. **Маршруты** - использовать Яндекс Router API для точного расчета времени доставки
3. **Геозоны** - более сложная логика зон доставки (полигоны вместо радиуса)
4. **Время работы** - проверка времени работы кафе при выборе времени
5. **Минимальная сумма** - проверка минимальной суммы заказа
