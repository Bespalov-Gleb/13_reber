**Для администраторов кафе**

Полное руководство по управлению ботом:
- 🚀 Начало работы и получение доступа
- 🍽️ Управление меню (категории, блюда, цены, фото)
- 📋 Управление заказами (статусы, курьеры, связь с клиентами)
- 👥 Управление пользователями (блокировка, роли, история)
- 💰 Управление платежами (подтверждение, возвраты, статистика)
- 📢 Система уведомлений (рассылки, шаблоны)
- 📊 Статистика и аналитика (выручка, популярные блюда, временная аналитика)
- 🎁 Управление промокодами (создание, типы, статистика)
- ⭐ Управление отзывами (просмотр, ответы, статистика)
- 🪑 Управление бронированиями (подтверждение, отмена, связь)
- 🚚 Управление курьерами (назначение, статистика, деактивация)
- 🔌 Интеграции (iiko CRM, Google Sheets, Яндекс.Карты)
- ⚙️ Настройки кафе (рабочее время, информация, доставка, платежи)
- 🆘 Решение частых проблем

### 🔌 [Руководство по интеграциям](integration_guide.md)
**Для технических специалистов**

Настройка внешних сервисов:
- 💳 **Платежные системы**
  - ЮKassa (основная система) — регистрация, ключи, webhook, тестирование
  - CloudPayments (резервная система) — настройка, webhook
  - Stripe (международные платежи) — ключи, настройка
- 🗺️ **Картографические сервисы**
  - Яндекс.Карты — API ключ, геокодирование, автоподсказки
  - Google Maps — альтернативный сервис
- 📊 **CRM и аналитика**
  - iiko CRM — API доступ, синхронизация меню, отправка заказов
  - Google Sheets — Service Account, экспорт аналитики
- 🌐 **Webhook endpoints** — nginx, SSL, тестирование
- 🔒 **Безопасность** — защита webhook, шифрование, ротация ключей
- 📊 **Мониторинг и логирование** — Prometheus, Grafana, ELK Stack
- 🐛 **Troubleshooting** — диагностика проблем с интеграциями
