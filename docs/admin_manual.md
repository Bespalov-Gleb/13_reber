## 🚀 Начало работы

### 🔑 Получение доступа к админ-панели

1. **Назначение роли администратора:**
   - Обратитесь к техническому администратору
   - Предоставьте ваш Telegram ID
   - Роль будет назначена в базе данных

2. **Первый вход:**
   - Отправьте команду `/start` боту
   - В главном меню появится кнопка "👨‍💼 Админ-панель"
   - Нажмите на неё для входа в админ-панель
   - Команда /admin также предоставляет вход в админ панель

3. **Проверка прав:**
   - Если кнопка не появляется, проверьте назначение роли
   - Убедитесь, что ваш Telegram ID корректно указан в системе

### 🏠 Интерфейс админ-панели

Админ-панель содержит следующие разделы:

- **🍽️ Управление меню** — категории и блюда
- **📋 Заказы** — управление заказами
- **📊 Статистика** — аналитика и отчеты
- **👥 Пользователи** — управление клиентами
- **💰 Платежи** — управление платежами
- **📢 Уведомления** — рассылки и уведомления
- **🪑 Бронирования** — управление столиками
- **🍽️ iiko CRM** — интеграция с iiko
- **🚚 Курьеры** — управление доставкой

## 🍽️ Управление меню

### 📂 Управление категориями

#### ➕ Добавление новой категории

1. Перейдите в **🍽️ Управление меню**
2. Нажмите **➕ Добавить категорию**
3. Введите название категории (например: "Горячие блюда")
4. Нажмите **✅ Сохранить**

**Примеры названий категорий:**
- 🍕 Пицца
- 🍝 Паста
- 🥗 Салаты
- 🍔 Бургеры
- 🥤 Напитки
- 🍰 Десерты

#### ✏️ Редактирование категории

1. Выберите категорию из списка
2. Нажмите **✏️ Редактировать**
3. Измените название
4. Нажмите **✅ Сохранить**

#### 🗑️ Удаление категории

⚠️ **Внимание!** При удалении категории будут удалены все блюда в ней.

1. Выберите категорию
2. Нажмите **🗑️ Удалить**
3. Подтвердите удаление
4. Все блюда в категории будут удалены

### 🍽️ Управление блюдами

#### ➕ Добавление нового блюда

1. Выберите категорию
2. Нажмите **➕ Добавить блюдо**
3. Заполните информацию:
   - **Название** (например: "Маргарита")
   - **Описание** (например: "Томаты, моцарелла, базилик")
   - **Цена** в рублях (например: 450)
   - **Фотография** (опционально)
4. Нажмите **✅ Сохранить**

**Советы по заполнению:**
- Используйте эмодзи в названиях для привлекательности
- Описание должно быть информативным, но кратким
- Цены указывайте в рублях (без копеек)
- Фотографии улучшают конверсию заказов

#### ✏️ Редактирование блюда

1. Выберите блюдо из списка
2. Нажмите **✏️ Редактировать**
3. Измените нужные поля:
   - Название
   - Описание
   - Цену
   - Фотографию
4. Нажмите **✅ Сохранить**

#### 🔄 Изменение цены

1. Выберите блюдо
2. Нажмите **💰 Изменить цену**
3. Введите новую цену
4. Нажмите **✅ Сохранить**

#### 📸 Обновление фотографии

1. Выберите блюдо
2. Нажмите **📸 Изменить фото**
3. Отправьте новое изображение
4. Фотография будет обновлена

#### 🗑️ Удаление блюда

1. Выберите блюдо
2. Нажмите **🗑️ Удалить**
3. Подтвердите удаление

#### ⏸️ Временное отключение

1. Выберите блюдо
2. Нажмите **⏸️ Отключить**
3. Блюдо исчезнет из меню, но останется в системе
4. Для включения нажмите **▶️ Включить**

## 📋 Управление заказами

### 📊 Просмотр заказов

#### 🔍 Фильтры заказов

В разделе **📋 Заказы** доступны следующие фильтры:

- **🆕 Новые** — заказы, ожидающие подтверждения
- **👨‍🍳 В приготовлении** — заказы, которые готовятся
- **✅ Готовые** — заказы, готовые к выдаче/доставке
- **🚚 В доставке** — заказы в процессе доставки
- **✅ Завершенные** — доставленные/выданные заказы
- **❌ Отмененные** — отмененные заказы

#### 📋 Детальная информация о заказе

При выборе заказа отображается:

- **📋 Номер заказа** — уникальный идентификатор
- **👤 Клиент** — имя и контакты
- **📅 Дата и время** — когда был сделан заказ
- **💰 Сумма** — общая стоимость
- **💳 Способ оплаты** — наличные/карта
- **📍 Адрес** — для доставки или самовывоз
- **📞 Телефон** — контактный номер
- **📝 Комментарий** — пожелания клиента
- **🍽️ Состав заказа** — список блюд с количеством

### 🔄 Управление статусами заказов

#### ✅ Принятие заказа

1. Выберите заказ со статусом "Новый"
2. Нажмите **✅ Принять**
3. Заказ перейдет в статус "В приготовлении"
4. Клиент получит уведомление

#### 👨‍🍳 Отметка "Готов"

1. Выберите заказ в статусе "В приготовлении"
2. Нажмите **✅ Готов**
3. Заказ перейдет в статус "Готовый"
4. Клиент получит уведомление

#### 🚚 Назначение курьера (для доставки)

1. Выберите заказ на доставку в статусе "Готовый"
2. Нажмите **🚚 Назначить курьера**
3. Выберите курьера из списка
4. Курьер получит уведомление о новом заказе

#### ✅ Отметка "Доставлен"

1. Выберите заказ в статусе "В доставке"
2. Нажмите **✅ Доставлен**
3. Заказ перейдет в статус "Завершен"
4. Клиент получит уведомление

#### ✅ Отметка "Выдан" (самовывоз)

1. Выберите заказ на самовывоз в статусе "Готовый"
2. Нажмите **✅ Выдан**
3. Заказ перейдет в статус "Завершен"

#### ❌ Отмена заказа

1. Выберите заказ
2. Нажмите **❌ Отменить**
3. Укажите причину отмены
4. Клиент получит уведомление об отмене

### 📞 Связь с клиентами

- **📞 Позвонить** — прямая ссылка для звонка
- **💬 Написать** — отправка сообщения через бота
- **📍 Адрес** — открытие в картах

## 🎁 Управление промокодами

### ➕ Создание промокода

1. Перейдите в **🎁 Промокоды**
2. Нажмите **➕ Создать промокод**
3. Заполните параметры:
   - **Код** (например: "WELCOME10")
   - **Тип скидки** — процент или фиксированная сумма
   - **Размер скидки** — 10% или 100₽
   - **Минимальная сумма** — от какой суммы действует
   - **Срок действия** — до какой даты
   - **Лимит использований** — сколько раз можно использовать
4. Нажмите **✅ Создать**

### 📊 Типы промокодов

#### 💰 Процентная скидка

- **Код**: "SUMMER20"
- **Скидка**: 20%
- **Минимум**: 500₽
- **Действует**: до 31.08.2024

#### 💵 Фиксированная скидка

- **Код**: "FIRST100"
- **Скидка**: 100₽
- **Минимум**: 800₽
- **Действует**: до 30.09.2024

#### 🎁 Бесплатная доставка

- **Код**: "FREEDELIVERY"
- **Скидка**: 0₽ на доставку
- **Минимум**: 1000₽
- **Действует**: постоянно

### ✏️ Редактирование промокода

1. Выберите промокод
2. Нажмите **✏️ Редактировать**
3. Измените нужные параметры
4. Нажмите **✅ Сохранить**

### 🗑️ Удаление промокода

1. Выберите промокод
2. Нажмите **🗑️ Удалить**
3. Подтвердите удаление

### 📊 Статистика промокодов

- **📈 Использований** — сколько раз использован

- **👥 Уникальных пользователей** — сколько человек использовали

## 🆘 Частые проблемы и решения

### ❌ Бот не отвечает

**Проблема**: Бот не реагирует на команды

**Решения**:
1. Проверьте интернет-соединение
2. Перезапустите бота
3. Проверьте логи на ошибки
4. Убедитесь, что токен бота корректный

### 🍽️ Меню не отображается

**Проблема**: Меню пустое или не загружается

**Решения**:
1. Проверьте наличие категорий и блюд
2. Убедитесь, что блюда активны
3. Проверьте подключение к базе данных
4. Перезагрузите меню из админ-панели

### 💳 Платежи не проходят

**Проблема**: Клиенты не могут оплатить заказ

**Решения**:
1. Проверьте настройки ЮKassa
2. Убедитесь в корректности webhook URL
3. Проверьте SSL сертификат
4. Проверьте логи платежной системы

### 📱 Уведомления не приходят

**Проблема**: Админ не получает уведомления о заказах

**Решения**:
1. Проверьте настройки ADMIN_CHAT_ID
2. Убедитесь, что бот добавлен в чат
3. Проверьте права бота в чате
4. Проверьте логи уведомлений

### 🗄️ Ошибки базы данных

**Проблема**: Ошибки при работе с базой данных

**Решения**:
1. Проверьте подключение к PostgreSQL
2. Убедитесь в корректности миграций
3. Проверьте права доступа к БД
4. Перезапустите базу данных
